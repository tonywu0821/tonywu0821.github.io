# Tony Wu — personal website

A responsive, static portfolio for [tonywu0821.github.io](https://tonywu0821.github.io/).

## Preview locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. No installation or build step is required.

## Edit

- `index.html`: introduction, work, technologies, and contact links.
- `css/custom.css`: layout, colours, typography, and responsive styles.
- `CV/Tony_Wu_CV.pdf`: current CV, linked from the homepage.

Google Fonts is optional; the page falls back to system fonts when unavailable.

## Publish

Push the reviewed changes to the branch configured in **Settings → Pages**.
This project serves directly from the repository root on GitHub Pages.
